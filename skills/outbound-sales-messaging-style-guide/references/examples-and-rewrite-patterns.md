# Examples and rewrite patterns

Use these patterns when the user wants a draft, a rewrite, or a critique. Keep the underlying offer and audience intact unless the user asks to change them.

## 1. Cold email

### Good shape
- Open with one reason the outreach is relevant.
- State the offer in one plain sentence.
- Ask for one small next step.
- Keep the body short enough to scan in one pass.

### Rewrite target
<Bad>
```text
Hope all is well. We help modern teams optimize outreach using an innovative platform that drives better results.
Would you be open to learning more?
```
</Bad>

<Good>
```text
I noticed your team is expanding outbound into a few new segments.
We help reps tailor first-touch emails without spending extra time on manual research.
Would it be useful if I sent a short example?
```
</Good>

## 2. Follow-up message

### Good shape
- Reference the prior message without sounding resentful.
- Add one new detail, reason, or angle.
- End with a light ask or an easy exit.

### Rewrite target
<Bad>
```text
Just following up again since I haven't heard back.
Please let me know if you're interested.
```
</Bad>

<Good>
```text
One more note in case it helps: this is usually most relevant when reps are sending the same message to several persona types.
If that is not a priority right now, no problem.
```
</Good>

## 3. LinkedIn DM

### Good shape
- Keep it short.
- Avoid sounding like a pitch deck.
- Use one concrete connection to the recipient’s role or situation.

### Rewrite target
<Bad>
```text
Loved your background and thought you might be the perfect person to talk to about our exciting platform.
```
</Bad>

<Good>
```text
Your team’s work on outbound personalization stood out to me.
I shared a short note because we help teams make first-touch messages feel more relevant without making them longer.
```
</Good>

## 4. SMS or very short outreach

### Good shape
- Use the fewest words that still make the ask understandable.
- Avoid stacked clauses and formal wording.
- Make the next step obvious.

### Rewrite target
<Bad>
```text
Hi, just wanted to reach out to see if you might have some time this week for a quick discussion about how we can potentially support your business objectives.
```
</Bad>

<Good>
```text
Hi — sending this because your team is growing outbound.
Worth sharing a 2-line example?
```
</Good>

## 5. Compliance-sensitive review

Use this check before approving a message:
- Is the claim supported by what the user supplied?
- Does the message imply familiarity the sender does not have?
- Would the recipient likely view this as pushy, deceptive, or out of place for the channel?
- Does the message respect the recipient’s role and the likely seriousness of the topic?

If one of those answers is no, flag it and suggest a safer rewrite.

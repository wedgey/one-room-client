# Project Scope Intake

Use this checklist to define a mobile app before design or development starts.

## Capture

- Product goal
- Primary user groups
- Core problem the app solves
- Target platforms: iOS, Android, or both
- Delivery model: native, cross-platform, or hybrid
- Timeline and budget
- Required integrations
- Data sensitivity and privacy constraints
- Offline requirements
- Device features needed: camera, GPS, notifications, Bluetooth, contacts, payments
- App store distribution plan

## Define

- Top 3 user journeys
- Must-have features
- Nice-to-have features
- Success metrics
- Known risks
- Out of scope items

## Decide early

- Authentication method
- Data storage location
- Backend ownership
- Analytics needs
- Accessibility targets
- Supported OS versions
- Localization needs

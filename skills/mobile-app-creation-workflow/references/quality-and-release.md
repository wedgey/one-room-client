# Quality and Release Checklist

Use this checklist before shipping a mobile app.

## Testing
- Test on at least 1 simulator and 1 real device per target platform
- Verify onboarding, login, logout, recovery, and session persistence
- Test poor network, airplane mode, and app relaunch behavior
- Test permissions prompts and denial paths
- Test form validation and error messaging
- Test accessibility basics: labels, contrast, scalable text, focus order
- Test app performance on low-end devices when relevant

## Release
- Confirm version number and build number
- Prepare store listing copy
- Prepare screenshots and preview assets
- Add privacy policy and data handling disclosures
- Verify permission strings and usage explanations
- Confirm crash reporting and analytics are enabled as intended
- Document rollback steps and hotfix ownership

## Store readiness
- Review app store guidelines for the target platforms
- Check age ratings and content declarations
- Verify account access for publishing
- Validate deep links and sign-in flows
- Confirm that all third-party SDKs are approved for release
